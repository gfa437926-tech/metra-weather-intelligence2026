# مركز التنبؤ الجوي — حالة الواجهة وعقد التكامل المقترح

**الحالة:** واجهة Flutter قيد الإكمال؛ مصدر دليل المحطات متصل بالكود، أما قياسات المحطات والنشرات اللحظية فلم تُربط بعد.  
**آخر تحديث:** 2026-11-11T13:16:39.784Z UTC

## ما أصبح متاحاً في الواجهة

- تحميل دليل المحطات من وظيفة `station-directory` المحمية بهوية المستخدم وصلاحية قراءة الدليل.
- بيانات المحطة المعروضة: المعرّف والرمز والاسم والنوع وحالة الاعتماد والحالة التشغيلية والإحداثيات الحالية والارتفاع `elevation_m`.
- مقارنة المحطات بالبحث والفرز حسب النوع، ونطاقات الارتفاع، وحدود خط العرض والطول، وحدود الارتفاع الدقيقة.
- فتح بطاقة المحطة لعرض بياناتها الموثقة وتفاصيل القياسات المطلوبة والنشرة الواردة.
- القيم غير المتوفرة تظهر كـ «لا توجد قراءة محملة» أو شرطة مع توضيح أنها **ليست صفراً** وليست قراءة فعلية.

## حدود التكامل الحالية

- وظيفة `station-directory` لا تعيد قياسات الأرصاد اللحظية؛ تعيد بيانات الدليل والإحداثيات والارتفاع.
- وظيفة `observations` الحالية مخصصة لسجل الرصد الذي أدخله المستخدم وقائمة مراجعة المحطة، ولا تمثل تدفق أجهزة القياس الآلية أو صندوق النشرات.
- لا توجد في هذا الفرع حالياً خدمة موثقة لقراءات المطر والرياح أو استقبال النشرات وفك ترميزها. لذلك لا يجوز عرض بيانات تجريبية على أنها مباشرة.
- لم يتم تعديل أي جدول أو تشغيل SQL أو migration أو تغيير بيانات أو أسرار.

## عقد قراءة مقترح — يحتاج مراجعة Backend والمراجعة العلمية

هذا **اقتراح واجهة تكامل وليس عقداً معتمداً**. يجب اعتماده من فريق Backend والمسؤول العلمي قبل التنفيذ.

### الطلب المقترح

`GET /functions/v1/forecast-centre?from=<ISO-UTC>&to=<ISO-UTC>&station_ids=<comma-separated-ids>`

- JWT إلزامي، والتحقق من الحساب النشط والصلاحيات ونطاق المحطات في الخادم.
- أسماء الصلاحيات المقترحة مؤقتاً: `forecast.center.read` مع `stations.read`، وتحتاج مواءمة مع كتالوج الصلاحيات الفعلي.
- لا يُرسل مفتاح service-role إلى تطبيق Flutter.
- يجب أن يحدد العقد نافذة التحديث وسياسة القيم القديمة (stale) وحدود حجم الاستجابة والترقيم.

### شروط القيم والجودة

- جميع التواريخ والأوقات UTC بصيغة ISO 8601، مع فصل `observed_at` عن `received_at`.
- `null` تعني قيمة غير متاحة؛ لا تستبدل بصفر.
- يجب تثبيت الوحدات ودلالة اتجاه الرياح ونافذة تراكم المطر في العقد العلمي قبل ربط القيم.
- تُعرض حالة المصدر وعمر القراءة ورايات الجودة بجوار القيمة، ولا تسمى القراءة «لحظية» إذا تجاوزت حد التقادم المتفق عليه.
- تُحفظ الرسالة الخام منفصلة عن الحقول المفككة، مع إصدار المحلل ونتيجة التحقق.
- لا تُنشأ مؤشرات مشتقة أو مقارنات تجميعية قبل اعتماد تعريفاتها العلمية.

## معايير قبول واجهة مركز التنبؤ

1. تحميل بيانات دليل المحطات من الخدمة المحمية، مع حالات تحميل/خطأ/عدم صلاحية/عدم وجود سجلات.
2. تطبيق فلاتر النوع والإحداثيات والارتفاع على بيانات فعلية من الدليل.
3. فتح تفاصيل المحطة وإظهار المصدر والحالة والارتفاع والإحداثيات الموثقة.
4. إظهار المطر 1/3/6/24 ساعة والرياح واتجاهها والهبات والحرارة والندى والضغط والرطوبة والرؤية والغيوم عند توافر تغذية معتمدة.
5. فتح النشرة الخام والمفككة مع وقت الاستلام وإصدار المحلل وسجل التحقق.
6. عدم عرض قيم مصطنعة أو إظهار الصفر بدلاً من القيمة المفقودة.
7. اختبار الصلاحيات ونطاق المحطات وفشل المصدر وتقادم القراءة واختلاف وقت الرصد عن وقت الاستلام.
