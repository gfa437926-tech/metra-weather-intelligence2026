## فجوة توافق التطبيق — مانع إطلاق حالي

خدمات Edge Functions الحالية ما زالت تستعلم أسماء الجداول القديمة في `public` مثل `station_catalogue`, `metra_account_states`, `metra_observations` وتستدعي RPCs قديمة. هذه الكائنات أزيلت ضمن إعادة التأسيس؛ لذلك **خدمات التطبيق الحالية غير متوافقة بعد مع المخطط الجديد**.

الخطوات البرمجية التالية قبل إعادة تشغيل تدفقات التطبيق:

1. استكمال إعداد login role مُدار يرث `metra_api_runtime`، وإضافة سلسلة الاتصال إلى مدير أسرار الاستضافة.
2. نشر .NET API وضبط `METRA_API_URL` وCORS.
3. استكمال إنشاء/تعديل المحطات والإدارة الكاملة للمستخدمين والأدوار والتشغيل والملفات والتصدير والتنبؤات وإدخال التنبيهات الرسمية.
4. اعتماد قاموس المعايير والوحدات والحدود العلمية من مختص أرصاد قبل تفعيل إدخال قياسات تشغيلية.
5. إضافة اختبارات تكامل وأمن على قاعدة اختبار فارغة تغطي المعاملات وBOLA/IDOR ودورة التسجيل والرصد والمراجعة.
6. استعادة ملفات SQL المصدرية للمخطط الأساسي حتى تصبح إعادة البناء من Git قابلة للتكرار.
